Cross-experiment sample correspondence — Skim · MolBreeding · BRB-seq

Which sample id in one experiment is the same biological NIL/check in another

Purpose

Curate, for every sample that has sequence data, the correspondence between the per-experiment PN#_SID# fastq sample id and the true biological identity — so we compare the right genome tracks across experiments.

The trap this fixes

All three experiments label fastqs with a PN#_SID# prefix (PN{ceil(SID/96)}_SID{SID}), but the plate number id is per-experiment, so the same prefix is a different biological sample across experiments. Concretely:

  • Skim (WGS low-coverage) and MolBreeding (target sequencing) share one id space — same PN#_SID# ⇒ same sample. (Skim-RTI on the SNP50K filter and Skim-BIN on the 27M wideseq filter are the same skim reads.)
  • BRB-seq (3′ RNA) has its own PN#_SID# space. Assuming it matched Skim/MolB by prefix is what previously compared incomparable samples.

Cross-experiment identity key = the pedigree string (drop the trailing .B the Skim/MolB registry carries; BRB pedigrees have none). The PN#_SID# prefix is not a cross-experiment key.

Scope and rules

  • In scope: the bzea/ZEAL population (project == "bzea") — teosinte-introgression NILs + the B73 and Purple checks. The landb/lanteo landrace lines are excluded (only a handful were sequenced anyway).
  • Sequence-data only: a sample appears only if it has reads — skim from the WGS BAM list (bam_list_1440, includes the checks), BRB from its coverage table. Metadata-only and out-of-scope rows are excluded.
  • Label: NILs → the pedigree string; checks → B73_<prefix> / Purple_<prefix> (each check is unique because checks cannot yet be matched across experiments — see Checks).
  • Sample class is read from Genotype/sample_group/accession, never the check column (it is unreliable — e.g. BRB “Purple Check” rows carry check="no").

library(readr); library(dplyr); library(stringr); library(tidyr); library(knitr)

chop <- function(x) sub("\\.B$", "", x)   # drop the trailing ".B"

## ---- samples WITH sequence data ----
skim_seq <- readLines(params$skim_seq)                              # skim WGS BAMs (PN#_SID#)
brb_seq  <- read_csv(params$brb_seq, show_col_types = FALSE)$name   # BRB sequenced

## ---- Skim / MolBreeding id space (shared) ----
master <- read_csv(params$master, show_col_types = FALSE) %>%
  mutate(pedigree = ifelse(pedigree %in% c("NA", ""), NA, pedigree),
         ped      = ifelse(!is.na(pedigree), chop(pedigree), NA),
         chk_grp  = ifelse(sample_group %in% c("B73", "Purple"), sample_group, NA))
## scope = the bzea/ZEAL population (project == "bzea"); landb/lanteo landrace lines are excluded.
skim_nil <- master %>% filter(project == "bzea", !is.na(ped),     sample %in% skim_seq) %>% transmute(skim_prefix = sample, pedigree = ped)
skim_chk <- master %>% filter(project == "bzea", !is.na(chk_grp), sample %in% skim_seq) %>% transmute(skim_prefix = sample, grp = chk_grp)

## ---- BRB-seq id space (own) ----
brbm <- read_csv(params$brb_meta, show_col_types = FALSE) %>%
  mutate(brb_prefix = sample_id,                              # already PN#_SID#
         is_nil  = str_detect(Genotype, "_P[0-9]"),           # real pedigree -> NIL
         chk_grp = case_when(Genotype == "B73" | accession == "B73"             ~ "B73",
                             accession == "Purple" | str_detect(Genotype, "Purple") ~ "Purple",
                             TRUE ~ NA_character_),
         ped     = ifelse(is_nil, chop(Genotype), NA))
brb_nil <- brbm %>% filter(is_nil,          brb_prefix %in% brb_seq) %>% transmute(brb_prefix, pedigree = ped)
brb_chk <- brbm %>% filter(!is.na(chk_grp), brb_prefix %in% brb_seq) %>% transmute(brb_prefix, grp = chk_grp)

## ---- MolBreeding target-seq (the 16 map rows ARE the sequenced set) ----
molb <- read_tsv(params$mb_map, show_col_types = FALSE) %>%
  transmute(prefix = sample_id, molb_geno = genotype, molb_ped = chop(genotype))

agg <- function(df, key, val) df %>% group_by(.data[[key]]) %>%
  summarise("{val}" := paste(sort(unique(.data[[val]])), collapse = ";"),
            "n_{val}" := n_distinct(.data[[val]]), .groups = "drop")

File 2 — MolBreeding 3-way (MolB · Skim · BRB-seq)

MolBreeding sequenced only 16 samples, so rather than a separate Skim↔︎MolBreeding file we give the full 3-way correspondence for those 16 — their MolB id, the shared Skim id, and (where the same NIL was also sequenced in BRB-seq) the BRB-seq id. MolBreeding and Skim share one id space (same PN#_SID#); the BRB-seq link is by pedigree and exists for only a few of the lines (MolBreeding and BRB-seq otherwise share no id space and overlap on just those NILs — hence the wide Skim↔︎BRB correspondence stays in File 1).

Code 
brb_by_ped <- brb_nil %>% group_by(pedigree) %>%
  summarise(brbseq_prefix = paste(sort(unique(brb_prefix)), collapse = ";"), .groups = "drop")

file2 <- molb %>%
  left_join(master %>% transmute(prefix = sample, skim_ped = ped, skim_grp = chk_grp), by = "prefix") %>%
  mutate(grp   = case_when(str_detect(molb_geno, "B73")    ~ "B73",
                           str_detect(molb_geno, "Purple") ~ "Purple",
                           !is.na(skim_grp)                ~ skim_grp,
                           TRUE ~ NA_character_),
         type  = ifelse(!is.na(grp), grp, "NIL"),
         label = ifelse(type == "NIL", molb_ped, paste0(grp, "_", prefix)),
         skim_prefix     = ifelse(prefix %in% skim_seq, prefix, NA_character_),
         pedigree_agrees = ifelse(type == "NIL", molb_ped == skim_ped, NA)) %>%
  left_join(brb_by_ped, by = c("molb_ped" = "pedigree")) %>%
  transmute(type, label, molb_prefix = prefix, skim_prefix, brbseq_prefix,
            molb_ped, skim_ped, pedigree_agrees,
            in_skim = !is.na(skim_prefix), in_brbseq = !is.na(brbseq_prefix)) %>%
  arrange(type, molb_prefix)
write_csv(file2, file.path(params$outdir, "molbreeding_3way_correspondence.csv"))

Unclassifiable sequenced samples

A sequenced bzea sample enters File 1 only if it is a NIL (has a pedigree) or a check (sample_group ∈ {B73, Purple}). Any sequenced sample that is neither — no pedigree and no check group — has reads but no identity to match on, so it is otherwise silently absent from the correspondence. They are listed here so the gap is not invisible. The only handle is the field_row (field-plot id); the upstream planting/field sheet (not on /Volumes/BZea) maps that plot to a genotype, and is where the gap must be resolved.
